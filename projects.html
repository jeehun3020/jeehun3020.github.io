📈 TrendDo — 보는 유행을 함께 해보는 문화로

🏆 KHUTHON 2026 우수상

TrendDo는 숏폼·알고리즘 안에서 빠르게 소비되고 사라지는 유행을 세대별 언어로 번역하고, 실제로 해볼 수 있는 ToDo 챌린지와 지역·전통문화 경험으로 전환하는 AI 문화 순환 플랫폼입니다.

"알고리즘은 사람을 더 오래 보게 만들지만, 문화는 더 깊게 경험되게 만들지 못한다." — TrendDo는 이 간극을 좁히는 4단계 루프를 제공합니다.

4단계 문화 루프

  • 1. 발견 (Trend Radar) — YouTube·Naver·seed 데이터에서 유행 자동 수집
  • 2. 이해 (Generation Guide) — 10대 / 30·40대 / 50·60대 / 가족 / 외국인 언어로 번역
  • 3. 행동 (Trend-Do Card) — 준비물·시간·비용·단계가 있는 ToDo 챌린지로 변환
  • 4. 재생산 (K-Culture Map / Admin Ops) — 지역 자산·전통문화와 융합, 문화 데이터화

핵심 AI 기능

  • OpenAI Responses API + Structured Output — Zod schema로 LLM 출력 검증, fallback 시 provenance_label=demo_seed로 기록
  • 지역 매칭 XAI 점수 — 카테고리·행동·소재·장소·일정·안전 6요소 기반 설명 가능한 매칭
  • Safety Gate — 초상권·개인정보·위험 행동·문화 왜곡 가능성 검수, 위험도 high는 자동 승인 차단
  • AI Ops Log — 모든 LLM 실행의 입력·출력·모델명·프롬프트 버전·생성 시간 추적
  • 지자체 제안 메일 초안 — 승인 전 자동 발송 없음, 검수 상태로 생성

지역 융합 예시

  • 두바이쫀득쿠키 + 강원 → 감자떡 쫀득 디저트 챌린지
  • 포토 챌린지 + 전주 → 한옥 골목 한 컷 리믹스
  • 러닝크루 + 진주 → 남강 유등 야간 무브 코스
  • 꾸미기 유행 + 전통공예 → 자개 패턴 키링 리믹스
